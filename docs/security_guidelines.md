# PowerController 보안 가이드라인 및 운영 보안 지침 (Security Guidelines)

본 문서는 **PowerController** 및 **PowerNetworkScheduler**의 네트워크 통신 아키텍처, 인증 체계, 식별된 보안 위협 및 안전한 기업/개인 환경 운영을 위한 보안 강화 가이드라인을 제공합니다.

---

## 🛡️ 1. 네트워크 통신 및 보안 아키텍처 개요

PowerController 제품군은 로컬 시스템 제어와 사내망 원격 통합 제어를 지원하기 위해 다음과 같은 네트워크 포트와 인증 계층을 사용합니다:

| 포트 번호 | 프로토콜 | 용도 및 기능 | 기본 보안 요구사항 |
| :--- | :--- | :--- | :--- |
| **TCP 9988** | TCP | 원격 스케줄 전송, 즉시 전원 제어, 상태 질의 | 보안 인증 토큰(`network_auth_token`) 또는 마스터 복구 키 인증 필수 |
| **UDP 9985** | UDP | 단방향 원격 스케줄 비동기 브로드캐스트 동기화 | 보안 인증 토큰 일치 시에만 수신 및 반영 |
| **UDP 9986** | UDP | 클라이언트 자동 검색 및 상태 브로드캐스트 (2초 주기) | 로컬 서브넷 내 식별 정보 (호스트명, IP, MAC, 토큰 설정 여부) |
| **TCP 59384** | TCP (Localhost) | 로컬 단일 인스턴스 뮤텍스 및 IPC 제어 | `127.0.0.1` 루프백 인터페이스 전용 (외부 인바운드 차단) |

---

## 🔍 2. 식별된 보안 취약점 및 개선 조치 내역

### 1) [보안 패치 완료] `set_token` 공백 인자 기반 인증 우회 결함 조치
* **취약점 분석**: `main.py`의 원격 토큰 설정 핸들러(`set_token`)에서 기존 토큰이 설정되어 있음에도 불구하고 요청 페이로드의 `auth_token`이 빈 문자열(`""`)로 전달될 경우 조건 검사가 누락되어 무인증으로 토큰이 덮어써질 수 있는 취약점이 존재했습니다.
* **개선 조치**: `server_token and server_token != client_token and not is_master_authorized`로 검증 로직을 강화하여, 기존 토큰과 정확히 일치하는 유효한 토큰 또는 마스터 복구 키가 검증되지 않으면 어떠한 경우에도 토큰 변경이 불가능하도록 원천 차단했습니다.

### 2) [보안 강화] 사전 명령어(`pre_command`) 실행에 대한 보안 감사 로깅 및 방어
* **위협 분석**: 스케줄에 시스템 배치 명령(`pre_command`)이 포함되어 전달될 경우 시스템에서 명령어가 실행될 수 있습니다.
* **개선 조치**:
  - 원격 네트워크를 통해 수신된 스케줄에 `pre_command`가 포함된 경우 보안 감사 경고 로그(`🚨 [보안 감사] 원격 사전 명령어 등록`)를 명시적으로 기록합니다.
  - 위험한 문자열 패턴 검증 및 비인가 네트워크 스케줄 등록 시 실행 권한을 엄격히 통제합니다.

### 3) [권고 사항] 하드코딩된 기본 마스터 복구 키(`DEFAULT_MASTER_RECOVERY_KEY`) 관리
* **위협 분석**: 소스 코드에 명시된 기본 비상 복구 키(`PowerRescue#2026!Admin`)를 그대로 사용할 경우, 내부망 공격자가 이를 악용할 수 있습니다.
* **개선 조치**:
  - **환경변수 지정**: 시스템 환경변수 `POWER_TIMER_MASTER_KEY`에 사내 전용 고유 비밀번호를 등록하여 기본 키를 오버라이드.
  - **설정 파일 지정**: 프로그램 실행 폴더에 `power_master_key.txt`를 배치하여 관리자 고유 키를 정의.

### 4) [암호학적 무결성] `ScheduleCrypto.dll` 기반 스케줄 데이터 위/변조 및 전원 공격 원천 차단
* **위협 분석**: 사내 배포용 예약 스케줄(`power_scheduler_rules.json`) 또는 원클릭 스케줄 주입기(`ApplySharedSchedules.exe`)의 내용이 공격자에 의해 악의적으로 조작되어 임의 시각에 시스템을 대량 종료시킬 위험 존재.
* **개선 조치**:
  - **HMAC-SHA256 디지털 서명 검증**: 스케줄 패키징 시 `ScheduleCrypto.dll`이 관리자 마스터 키 기반의 32바이트 HMAC 서명을 생성하여 데이터에 결합.
  - **주입 전 무결성 검증 (`verify_embedded_integrity`)**: 타깃 PC에서 주입기 실행 시 서명이 일치하지 않거나 1비트라도 변조된 경우 주입을 즉각 거부(`-2`)하고 보안 경고를 표출.
  - **Salt 결합 암호화 봉투**: 평문 노출을 방지하기 위해 16바이트 솔트와 키스트림 암호화가 결합된 Base64 보안 봉투 직렬화 적용.

### 5) [세션 및 하드웨어 보안] `SysPowerHook.dll` 기반 화면 잠금 감시 및 배터리 위험 수위 보호
* **위협 분석**: 사용자가 자리를 비우거나 화면을 잠갔을 때(`Win + L`) 비인가 접근 또는 정전/배터리 방전 시 작업 중인 데이터가 유실될 위험 존재.
* **개선 조치**:
  - **Windows 세션 알림 감시 (`WTSRegisterSessionNotification`)**: 화면 잠금 및 RDP 원격 접속 이벤트를 0.0% CPU 부하로 실시간 감지하여 자리 비움 보안 모니터링 수행.
  - **하드웨어 배터리 위험 수위(10% 이하) 감지**: AC 전원 분리 상태에서 배터리 잔량이 10% 이하로 떨어지면 즉각 안전 자동 전원 관리 알림 및 시스템 보호 조치 격발.

## ⚙️ 3. 운영 환경별 보안 강화 실천 수칙

### 🏢 A. 사내망 / 엔터프라이즈 환경 운영 지침
1. **사내 전용 마스터 키 의무 설정**:
   - 중앙 배포 시 각 엔드포인트에 `power_master_key.txt` 파일을 함께 배포하거나 GPO(그룹 정책)를 통해 `POWER_TIMER_MASTER_KEY` 환경변수를 사내 보안 표준에 맞는 난수로 지정하십시오.
2. **복합 보안 토큰 설정**:
   - 영문 대소문자, 숫자, 특수문자를 혼합한 12자리 이상의 강력한 보안 인증 토큰(`network_auth_token`)을 설정하십시오.
3. **네트워크 세그먼트 분리 (VLAN/VPN)**:
   - 전원 관리 제어 패킷이 공용 Wi-Fi나 외부 인터넷 세그먼트에 노출되지 않도록 전용 관리망(Management VLAN) 또는 사설 서브넷 내에서만 포트(TCP 9988, UDP 9985/9986)를 허용하십시오.
4. **일반 사용자 PC 원격 수신 옵션 관리**:
   - 관리 대상이 아닌 PC 또는 민감한 연구/임원용 PC는 메인 설정 화면에서 **"원격 예약 수신 활성화"** 체크를 해제하여 인바운드 제어를 원천 차단하십시오.

### 🏠 B. 개인 / 소규모 환경 운영 지침
1. **공용 네트워크(카페, 공항 Wi-Fi 등) 사용 시**:
   - Windows 방화벽 설정을 "공용 네트워크"로 유지하여 포트 9988에 대한 외부 접속을 차단하십시오.
2. **토큰 미설정 상태 방지**:
   - 클라이언트 설정에서 보안 토큰을 공백으로 두지 말고 개인 비밀번호를 지정해 두십시오.

## 🚨 4. 비상 복구 및 토큰 초기화 절차

관리자가 개별 PC에 설정된 보안 인증 토큰을 분실한 경우 아래의 공인된 복구 절차를 사용합니다:

1. **GUI 기반 비상 복구**:
   - `PowerNetworkScheduler.exe`의 **[🚨 토큰 분실 복구]** 메뉴를 열고 마스터 복구 키를 입력하여 원격 토큰을 강제 재설정하거나 조회.
2. **CLI 기반 즉시 초기화 (로컬)**:
   - 클라이언트 PC의 커맨드 라인에서 `PowerController.exe --reset-token`을 실행하여 로컬 설정 파일의 토큰을 즉시 초기화.
3. **GUI 설정 화면 초기화**:
   - 클라이언트 PC의 메인 화면 하단 네트워크 보안 섹션에서 **[토큰 초기화]** 버튼을 직접 클릭하여 재설정.

## 📋 5. 정기 보안 점검 체크리스트

| 점검 항목 | 권장 주기 | 확인 방법 |
| :--- | :--- | :--- |
| **마스터 복구 키 커스텀 여부** | 분기별 | `power_master_key.txt` 또는 환경변수 확인 |
| **보안 토큰 설정 상태** | 월별 | 메인 화면 네트워크 설정 탭 또는 스케줄러 상태 조회 |
| **원격 수신 옵션 적정성** | 반기별 | 불필요한 엔드포인트의 원격 수신 체크 해제 여부 |
| **Windows 방화벽 인바운드 규칙** | 시스템 변경 시 | 사설 네트워크에만 TCP 9988 허용 여부 |
