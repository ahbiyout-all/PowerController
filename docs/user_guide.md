# PowerController 사용자 가이드 (User Manual)

본 문서는 **PowerController v2.9.1** 전원 자동 오프 제어기의 다양한 핵심 기능을 일반 사용자의 관점에서 친숙하고 자세하게 설명하는 통합 가이드북입니다.

---

## 💡 주요 기능 소개 (Core Features)

PowerController는 단순한 종료 예약기를 넘어 데스크톱의 편리함을 극대화하고 시각적 감성을 강조한 **하이브리드 데스크톱 전원 관리 보조 시스템**입니다.

### 1. ⏱ 실시간 간편 제어 및 시간 타이머 (Timer)
*   **지연 타이머 예약**: "몇 시간, 몇 분, 몇 초 후에 컴퓨터를 꺼줘"와 같은 시간 차원 지연을 세밀하게 제어할 수 있습니다.
*   **특정 시각 고정 시간표 예약**: 정확한 특정 시간(예: 오후 11시 30분 정각)을 맞추어 전원 명령을 하사할 수 있습니다.
*   **다양한 전원 제어 모드**: `전원 종료(Shutdown)`, `재시작(Restart)`, `절전(Sleep)`, `화면 끄기(Screen Off)`, `로그아웃(Log Out)`, `알람(Alarm)` 등 6가지 제어 모드를 광범위하게 지원합니다.

### 2. 📅 고급 다중 스케줄러 (Scheduler)
*   **다차원 주기/요일 반복 플랜**: 매일 반복, 평일/주말 반복, 특정 요일 선택 반복, 특정 시각 1회 실행, 특정 시간 간격 주기(Interval) 구동을 지원합니다.
*   **원클릭 타임스탬프 도구**: 스케줄 이름 작성 시 `[앞에 추가]`, `[뒤에 추가]` 버튼을 눌러 현재 시각(`[YYYY-MM-DD HH:mm]`)을 손쉽게 제목 메모에 삽입할 수 있습니다.
*   **스마트 기본값**: 스케줄 추가 시 전원 행동의 기본값이 가장 빈번히 사용되는 **'종료(Shutdown)'**로 기본 설정되어 빠른 작업이 가능합니다.

### 3. 📌 상단 고정 컴팩트 위젯 맞춤 커스터마이저 (Floating Widget Customizer)
화면 한구석에 상시 띄워두고 현재 시각 및 카운트다운을 모니터링할 수 있는 상단 고정 위젯이 대폭 진화했습니다.
*   **5가지 위젯 스타일 테마**:
    1.  **네온 링 (Neon Ring)**: 세련된 원형 프로그레스 다이얼과 감각적인 네온 액센트.
    2.  **사이버 HUD (Cyber HUD)**: 하이테크 미래지향 텔레메트리 바와 정밀 데이터 뷰.
    3.  **슬림 바 (Slim Bar)**: 화면 공간을 최소화하는 초슬림 가로형 인디케이터.
    4.  **레트로 LED (Retro LED)**: 전광판/터미널 스타일의 디지털 그린 LED 디스플레이.
    5.  **클린 카드 (Clean Card)**: 모던하고 깔끔한 미니멀리즘 단색 카드.
*   **실시간 치수 및 폰트 슬라이더**:
    *   **위젯 너비 조절**: 260px부터 460px까지 원하는 크기로 위젯 폭을 조절합니다.
    *   **시계 글자 크기**: 9px부터 18px까지 디지털 시계 크기를 세밀하게 가감합니다.
    *   **타이머 글자 크기**: 16px부터 36px까지 카운트다운 숫자의 크기를 시원하게 확대/축소합니다.
*   **위젯 투명도 조절 (`widgetOpacity`)**: 30% ~ 100%까지 투명도를 조절하여 다른 작업 창을 가리지 않도록 설정합니다.

### 4. 🔔 매 정각 알림 차임벨 기능 (Hourly Chime)
*   매 시 정각(00분 00초)마다 은은한 시계 종소리 멜로디와 함께 토스트 팝업으로 현재 시각을 안내합니다.
*   환경 설정의 `사운드 및 알림` 섹션에서 자유롭게 켜거나 끌 수 있습니다.

### 5. 📅 부팅/시작 시 오늘 예약 작업 트레이 브리핑 (Startup Tasks Tray Alert)
*   프로그램 실행 시 오늘의 요일/날짜에 해당하는 활성 예약 작업(매일 반복, 오늘 요일 반복 등)이 있는지 자동 스캔합니다.
*   예약이 존재할 경우 메인 화면을 가로막지 않고, **시스템 트레이(화면 우측 하단 작업표시줄 위)에서 부드러운 페이드인과 함께 전용 브리핑 팝업 카드**가 나타나 오늘 실행될 스케줄 목록과 시각을 선제 안내합니다.
*   팝업에서 `[스케줄러 열기]`를 클릭하면 즉시 스케줄러 관리 창으로 이동하여 일정을 조정할 수 있습니다.

### 6. ⚙️ 환경설정 안전 버퍼링 (Confirm / Cancel)
*   환경설정 모달 창에서 테마, 폰트, 위젯 크기, 투명도 등의 옵션을 조작할 때 즉시 영구 저장되지 않고 임시 버퍼에 기록됩니다.
*   **'확인 (적용)'** 버튼을 클릭할 때만 실제 시스템에 일괄 반영 및 저장되며, **'취소'** 또는 닫기(`X`)를 누르면 이전 설정 상태로 안전하게 복원됩니다.

### 7. ⭐️ 즐겨찾기 보관함 (Favorites Manager)
*   자주 사용하는 지연 타이머 패턴(예: "영화 감상 후 2시간 뒤 자동 종료", "점심시간 1시간 빠른 리부팅")을 등록하여 원클릭으로 가동할 수 있습니다.

### 8. ⏰ 예약작업 알림 대기시간 설정 (Grace Warning Countdown)
*   예약 작업 실행 직전 사용자에게 취소 기회를 제공하는 카운트다운 안내창의 지속 시간을 5초부터 5분까지(5초/10초/20초/30초/1분/3분/5분) 자유롭게 조절할 수 있습니다.

### 9. ⚡ 실행 중인 프로그램 강제 종료 플래그 (/f 파라미터)
*   **기능 목적**: 컴퓨터가 종료되거나 재부팅될 때, 저장되지 않은 문서(메모장 등)나 응답이 지연되는 앱이 "저장하시겠습니까?" 창을 띄우며 시스템 종료를 중단시키지 않도록 Windows `/f` 파라미터를 강제로 적용합니다.
*   **기본값 (Default: Enabled)**: 사용자가 따로 건드리지 않아도 처음부터 **옵션 활성화 상태**로 작동하여 취침이나 외출 시 확실한 전원 차단을 보장합니다.
*   **손쉬운 제어**:
    *   **타이머 화면 상단**: `⚡ 실행 중인 앱 강제 종료 (/f)` 체크박스를 통해 필요할 때 언제든 즉각 ON/OFF 가능.
    *   **환경설정 모달**: `[6. 실행 중인 프로그램 강제 종료]` 섹션에서 기본 설정값을 저장 관리.
    *   **가상 시뮬레이터**: 플래그 활성화 시 `⚡ 실행 중인 앱 강제 종료 플래그 (/f) 적용됨` 배지가 시각적으로 점등.

### 10. 💻 개발 서버 포트 커스터마이징 및 충돌 방지
*   로컬 개발 환경에서 다른 웹 서버가 이미 포트 3000을 점유하고 있을 때, 포트 충돌 없이 개발할 수 있도록 다중 포트 실행 스크립트를 지원합니다:
    *   `npm run dev:4000`: 포트 4000으로 즉시 실행
    *   `npm run dev:5000`: 포트 5000으로 즉시 실행
    *   `CUSTOM_PORT=xxxx npm run dev`: 원하는 포트로 자유롭게 지정
*   AI Studio 클라우드 환경(포트 3000)과의 100% 호환성을 유지합니다.

### 11. 📐 2열 대칭 옵션 체크박스 및 10pt 고해상도 가독성 최적화 (v2.8.1)
*   **2열 대칭 레이아웃**: 메인 창 상단의 핵심 옵션 체크박스가 좌우 2열 대칭 구조로 정돈되어, 텍스트가 겹치거나 우측으로 잘리는 현상이 완벽히 해소되었습니다:
    *   `[📌 상단 고정]` | `[🖥️ 스케줄러 팝업창 열기]`
    *   `[⚙️ 시작 시 자동 실행]` | `[📥 부팅 시 트레이]`
    *   `[📁 최소화 시 트레이]` | `[⚡ 강제 닫기 (/f)]`
    *   `[📡 원격 예약 수신 허용 (포트 9988)]` (전체 가로폭 확보)
*   **10pt 시인성 하한선**: 모든 라벨, 버튼, 안내 문구의 글꼴 크기를 최하 10pt로 상향하여 고해상도(QHD, 4K) 모니터에서도 선명하게 읽을 수 있습니다.
*   **팝업창 자동 크기 맞춤(Auto-fit)**: 안내 메시지 내용의 길이에 따라 창 크기가 자동으로 유연하게 조절됩니다.

### 12. 🛡️ Windows Defender 방화벽 무음 통과 및 조직 관리 차단 해소 (v2.8.1)
*   메인 및 커맨더 프로그램이 설치 프로그램(`PowerController.iss`) 또는 기동 시 방화벽 규칙을 자동으로 사전 등록하여, 공용 네트워크 접속 시에도 "이 설정은 조직에서 관리합니다" 보안 팝업이 일절 발생하지 않습니다.
*   포터블 사용자는 프로그램 폴더의 `Register_Firewall_Rules.bat` 파일을 마우스 우클릭 후 **[관리자 권한으로 실행]**하여 원클릭으로 방화벽을 영구 승인할 수 있습니다.

### 13. 🎯 10대 인기 스케줄 프리셋 원클릭 자동 완성 (v2.9.0)
*   스케줄러 창 상단의 **[💡 인기 프리셋 불러오기]** 드롭다운 메뉴를 통해 가장 자주 사용되는 10가지 전원 시나리오를 원클릭으로 폼에 자동 완성할 수 있습니다:
    1.  `🏢 정시 퇴근 자동 종료`: 평일(월~금) 18:30 시스템 종료
    2.  `🌙 야간 심야 자동 종료`: 매일 23:30 시스템 종료
    3.  `☕ 점심시간 절전 모드`: 평일(월~금) 12:00 절전 모드
    4.  `🔄 월요일 아침 정기 리부팅`: 월요일 08:30 시스템 재시작
    5.  `💾 금요일 퇴근 전 백업 알림`: 금요일 18:00 알람 및 사전 명령어
    6.  `⚡ 1시간 후 빠른 종료`: 현재 시각 기준 1시간 후 즉각 종료
    7.  `💤 30분 무작업 시 절전`: 유휴 30분 감지 시 자동 절전
    8.  `📺 모니터 화면 즉시 끄기`: 야간 다운로드 시 화면 즉시 절전
    9.  `⏰ 정기 시스템 점검 리셋`: 매주 일요일 새벽 04:00 시스템 재부팅
    10. `🚨 긴급 정지 비상 알람`: 지정 시각 비프 경고 및 작업자 호출
*   프리셋을 선택하면 규칙명, 전원 모드, 시각, 요일, 경고문, 강제 종료 플래그(`/f`)가 즉시 최적의 값으로 자동 채워집니다.

### 14. 🛑 원격 대상 PC 즉시 전원 제어 (Immediate Power Actions) (v2.9.0)
*   독립형 네트워크 스케줄러(`PowerNetworkScheduler.exe`)에서 특정 원격 PC를 선택한 후, 대기 시간 없이 즉시 원격 제어할 수 있는 긴급 제어 명령을 지원합니다:
    *   `🛑 대상 PC 즉시 종료 (Shutdown Now)`: 대상 컴퓨터를 즉각 안전하게 전원 종료.
    *   `🔄 대상 PC 즉시 다시시작 (Reboot Now)`: 원격 업데이트 적용 또는 시스템 리셋을 위해 즉시 재부팅.

### 15. 📜 라이선스 및 약관 고지서 한국어/영어 2종류 실시간 전환 열람 (v2.9.1)
*   메인 창 하단의 **[📄 라이선스 및 약관 동의 고지서]**를 클릭하면 오픈소스 및 사용권 계약서 전문 팝업이 나타납니다.
*   팝업 상단의 **`[ 🇰🇷 KO ]` / `[ 🇺🇸 EN ]`** 버튼을 클릭하여 한국어 및 영어 2종류의 표준 MIT 라이선스 및 서드파티 라이브러리(pystray, Pillow, PyInstaller, Tkinter) 고지사항을 자유롭게 전환하여 열람할 수 있습니다.
*   안전 수칙: 라이선스 고지서 열람 시 실행 중이던 예약 타이머는 오작동 방지를 위해 즉시 안전 정지됩니다.

### 16. 🔐 네트워크 보안 인증 토큰 및 마스터 비상 복구 키 (v2.9.1)
*   원격 제어 무단 침입을 방지하기 위해 클라이언트마다 고유한 **보안 인증 토큰(`network_auth_token`)**을 설정할 수 있습니다.
*   관리자가 토큰을 분실한 경우 `PowerNetworkScheduler.exe`의 **[🚨 토큰 분실 복구]** 비상 복구 센터에서 마스터 비상 복구 키(`POWER_TIMER_MASTER_KEY` 또는 `power_master_key.txt`)를 입력하여 원격 토큰을 안전하게 재설정하거나 조회할 수 있습니다.

### 17. 🔒 Windows 세션 훅 기반 화면 잠금(Win+L) 및 자리 비움 감지 (v2.9.1)
*   `SysPowerHook.dll`을 통해 사용자가 자리를 비우거나 화면을 잠갔을 때(`Win + L`) 이를 즉각 실시간으로 감지하여 토스트 알림을 표출하고, 절전 타이머와 연동하여 불필요한 전력 소모를 방지합니다.

### 18. 🔋 하드웨어 배터리 / UPS 위험 수위(10%) 자동 보호 (v2.9.1)
*   노트북 및 UPS 사용 환경에서 AC 전원 분리 상태로 구동 중 배터리 잔량이 10% 이하로 떨어지면, 작업 중인 데이터 손실을 막기 위해 위험 경고 알림을 발동하고 안전한 전원 관리를 유도합니다.

### 19. 🛡️ 스케줄 배포 및 주입기 전자 서명(HMAC-SHA256) 무결성 검증 (v2.9.1)
*   `ScheduleCrypto.dll`을 통해 사내 배포용 원클릭 스케줄 주입기(`ApplySharedSchedules.exe`) 생성 시 SHA-256 해시 및 HMAC 전자 서명이 자동 임베딩됩니다.
*   다른 PC에서 주입기 실행 시 서명 일치 여부를 사전 검증하여, 파일이 임의로 조작되었거나 악의적으로 변조된 경우 주입을 즉각 차단합니다.

### 20. ⚡ 0.0001초 초고속 화면 잠금 및 모니터 절전 (v2.9.1)

## 🌐 네트워크 원격 스케줄러 (Network Remote Scheduler)

*   **Sender (송신)**: 동일 LAN 내 타 PC의 IP와 9988 포트로 예약 스케줄을 무선 전송.
*   **Receiver (수신)**: 수신 대기 상태에서 전송된 규칙을 받아 `power_scheduler_rules.json`에 자동 영구 삽입.

---

## 💾 원클릭 스케줄 복사 배포기 (Schedule Share Injector)

*   폐쇄망 및 다이렉트 소켓 통신이 불가능한 환경을 위해, 마스터 규칙이 포함된 단일 실행 파일(`ApplySharedSchedules.exe`)을 원클릭으로 생성하여 USB 등으로 배포 및 자동 동기화할 수 있습니다.
*   스케줄 변경 시 `schedule_share_builder.py`가 실시간으로 자동 갱신됩니다.
