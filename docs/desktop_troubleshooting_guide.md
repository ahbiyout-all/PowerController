# PowerController 데스크톱 앱 문제 해결 및 빌드 가이드 (Desktop App Troubleshooting & Build Guide)

본 문서는 데스크톱 애플리케이션(`main.py` 및 컴파일된 `PowerController.exe`)에서 **"수정된 내용이 데스크톱 앱에 적용되지 않는 현상"**의 원인과 해결 방법, 그리고 최신 소스 코드를 실행 파일로 빌드 및 배포하는 절차를 상세히 안내합니다.

---

## 🔍 1. "수정된 내용이 데스크톱 앱에 적용 안 됨" 현상 분석 및 원인

사용자 또는 개발자가 소스 코드를 변경하거나 설정을 저장했음에도 불구하고 데스크톱 앱에 반영되지 않는 현상은 주로 다음 **두 가지 핵심 원인**에 의해 발생합니다.

### 🔴 원인 1: 소스 코드(`main.py`) 수정 후 실행 파일(`.exe`) 재빌드 미실행
* **상황**:
  * 파이썬 스크립트 파일(`main.py`)을 수정하더라도, 이미 컴파일된 독립 실행 파일(`dist\PowerController.exe` 또는 설치된 `PowerController.exe`)은 이전 소스 코드가 동결(Frozen)되어 패키징된 상태입니다.
  * 따라서 수정된 소스를 실행 파일에 적용하려면 반드시 **빌드 스크립트(`build.bat`)를 실행하여 새로운 바이너리로 컴파일**해야 합니다.
* **증상**:
  * 새로 추가된 UI 위젯 테마, 차임벨 소리, 팝업 창 등의 최신 코드가 실행 파일에서 나타나지 않음.

---

### 🔴 원인 2: Windows UAC(사용자 계정 컨트롤) 권한 차단으로 인한 설정 저장 실패
* **상황**:
  * 인스톨러(`installer.py`)를 통해 설치하거나 `C:\Program Files\PowerController\` 경로에 앱을 배치한 경우, 해당 디렉터리는 Windows 보안 정책상 **관리자 권한(Administrator Privileges)** 없이는 일반 사용자가 파일을 생성하거나 수정할 수 없습니다.
  * 기존 구조에서는 설정 파일(`power_timer_settings.json`, `power_schedules.json`, `power_history.json`)을 프로그램 실행 파일과 동일한 디렉터리에 기록하려 하였고, 일반 사용자 권한 실행 시 `PermissionError`가 무시(pass)되면서 **설정이나 스케줄이 영구 저장되지 않고 앱 종료 시 사라지는 문제**가 발생했습니다.
* **증상**:
  * 환경설정에서 위젯 테마, 폰트, 투명도를 바꾸거나 새 스케줄을 추가해도 앱을 껐다 켜면 이전 기본값으로 초기화됨.

---

### 🔴 원인 3: Windows 보안 '공용 네트워크에서 이 앱에 액세스하도록 허용하시겠습니까?' 팝업 및 [허용] 버튼 비활성화 (v2.8.1 해결)
* **상황**:
  * 원격 예약 제어 기능(포트 9988 TCP 수신 리스너)이 구동될 때, Windows Defender 방화벽이 외부 소켓 바인딩을 감지하고 보안 팝업을 호출합니다.
  * 특히 **회사/학교/도메인 관리 환경(Active Directory, GPO, Intune)**이나 공용 Wi-Fi로 설정된 PC의 경우, **"⚠️ 이 설정은 조직에서 관리합니다"**라는 경고와 함께 하단의 **[허용] 버튼이 회색으로 비활성화**되어 일반 사용자가 팝업을 통과하거나 닫을 수 없는 현상이 발생합니다.
* **증상**:
  * 프로그램 실행 시마다 방화벽 경고 팝업이 뜨고 [허용]을 누를 수 없어 [취소]를 누르면 원격 기능이 차단됨.

## 🛠️ 2. 아키텍처 개선 및 영구 해결 방안 (v2.7.0 적용 완료)

### ✅ 해결책 A: `%APPDATA%\PowerController\` 안전 저장소 분리 (`get_data_filepath`)
PowerController v2.7.0부터는 프로그램 구동 시 쓰기 권한을 자동으로 사전 검사하고, 안전한 사용자 데이터 경로로 분기하는 `get_data_filepath(filename)` 함수를 탑재했습니다.

1. **동작 원리**:
   * 현재 실행 디렉터리에 쓰기 권한이 있는지 임시 파일 생성 테스트를 수행합니다.
   * `C:\Program Files\` 등 보호된 디렉터리이거나 쓰기 권한이 없는 경우, Windows 표준 사용자 데이터 디렉터리인 **`%APPDATA%\PowerController\`** (`C:\Users\<사용자명>\AppData\Roaming\PowerController\`) 경로를 생성하고 해당 위치에 설정 및 데이터 파일을 저장합니다.
2. **무손실 마이그레이션**:
   * 기존 실행 디렉터리에 구버전 설정 파일이 남아있는 경우, 새 `%APPDATA%` 폴더로 데이터를 자동 복사하여 사용자의 기존 스케줄과 설정이 유실되지 않도록 보장합니다.
3. **영구 지속성 확보**:
   * 일반 사용자 권한으로 실행하더라도 `%APPDATA%`에는 100% 쓰기 권한이 보장되므로, 모든 테마, 스케줄, 타이머 설정이 안전하게 영구 저장됩니다.

---

### ✅ 해결책 B: 소스 코드 수정 후 데스크톱 실행 파일 컴파일 (`build.bat`)
수정된 최신 기능(5종 미니 위젯 테마, 정각 차임벨, 부팅 시 오늘 작업 브리핑 등)을 데스크톱 실행 파일에 반영하기 위해 다음 절차를 따릅니다.

#### 🚀 1단계: Windows 명령 프롬프트(CMD) 또는 배치 파일 실행
프로젝트 루트 디렉터리에서 `build.bat`을 실행합니다:
```bat
build.bat
```

#### 📦 2단계: 자동 빌드 프로세스 수행
`build.bat`은 내부적으로 다음 단계를 자동으로 처리합니다:
1. 파이썬 환경 및 필수 라이브러리(`pyinstaller`, `pillow` 등) 확인
2. 최신 버전 번호(`v2.8.0`) 및 메타데이터(`version_*.txt`) 자동 바인딩
3. 다음 실행 파일 4종 생성 (`dist\` 디렉터리):
   * `dist\PowerController.exe`: 메인 스마트 전원 제어 에이전트
   * `dist\PowerNetworkScheduler.exe`: 독립형 네트워크 원격 스케줄 전송기
   * `dist\ApplySharedSchedules.exe`: 스케줄 자동 주입기
   * `dist\PowerController_Setup_v2.8.0.exe`: Inno Setup 6 기반 공식 통합 인스톨러

#### 🏃‍♂️ 3단계: 컴파일된 새 실행 파일 실행
* 개발/테스트 중에는 `dist\PowerController.exe`를 직접 실행하거나,
* 파이썬 인터프리터로 실시간 소스를 바로 실행할 수 있습니다:
  ```bash
  python main.py
  ```

### ✅ 해결책 C: Windows Defender 방화벽 3중 사전 무음 등록 체계 (v2.8.1 적용 완료)
공용 네트워크 보안 경고 및 조직 관리 차단 팝업을 원천 차단하기 위해 3단계 방화벽 사전 등록 체계가 구축되었습니다:

1. **설치 단계 사전 등록 (`PowerController.iss`)**:
   * 인스톨러 실행 시 이미 획득한 관리자 권한(`PrivilegesRequired=admin`)을 통해 **메인(`PowerController.exe`) 및 커맨더(`PowerNetworkScheduler.exe`)** 둘 다 모든 프로필(도메인/개인/공용, `profile=any`)에 대해 인바운드/아웃바운드 허용 규칙을 사전 주입합니다.
   * 이에 따라 설치 후 첫 실행 시에도 Windows는 이미 등록된 규칙으로 인식하여 UAC 보안 팝업을 일절 띄우지 않습니다.
2. **프로그램 내부 무음 자동 점검 (`ensure_firewall_rule_silent`)**:
   * 메인 앱과 커맨더 앱 기동 시 백그라운드(`CREATE_NO_WINDOW`)에서 `netsh advfirewall` 명령을 실행하여 누락된 방화벽 규칙을 자동으로 보완 등록합니다.
3. **독립형 원클릭 배치 스크립트 (`Register_Firewall_Rules.bat`)**:
   * 포터블 사용자나 사내 IT 관리자는 프로그램 폴더의 `Register_Firewall_Rules.bat` 파일을 우클릭 후 **[관리자 권한으로 실행]**하면 즉시 모든 규칙이 등록됩니다.

### ✅ 해결책 D: 원격 무인 설치 시 프로세스 강제 종료 및 파일 락 우회 (`v2.9.1` 적용 완료)
원격 관리 도구(GPO, Intune, PsExec)를 통해 무인 설치 진행 시 기존 백그라운드 프로세스가 파일 핸들을 점유하고 있어 설치가 멈추거나 실패하는 문제를 원천 차단했습니다:

1. **다계층 강제 종료 파이프라인**:
   - 로컬 소켓 리스너(포트 59384)에 `QUIT` 신호 선제 발송.
   - `taskkill /F /T /IM PowerController.exe`, PowerShell `Stop-Process -Force`, WMIC 프로세스 강제 종료 3중 트리거 실행.
2. **파일 락 자동 우회 (`.old_XXXX` 리네이밍)**:
   - 파일 잠금(`ERROR_SHARING_VIOLATION`) 발생 시 기존 실행 파일의 이름을 임시 파일(`.old_XXXX`)로 즉시 변경하여 락을 우회하고 새 바이너리를 중단 없이 100% 주입.

## 📋 3. v2.9.1 신규 기능 정상 반영 확인 체크리스트

빌드 완료 후 `dist\PowerController.exe` 및 `PowerNetworkScheduler.exe`를 실행하여 다음 사항을 확인하십시오:

- [ ] **메인 창 하단 버전 표시**: `버전: v2.9.1` (또는 최신 빌드 버전)으로 표기되는지 확인.
- [ ] **10대 인기 스케줄 프리셋**:
  - `스케줄러` 창에서 **[💡 인기 프리셋 불러오기]** 클릭 시 10종 시나리오가 원클릭으로 폼에 자동 채워지는지 확인.
- [ ] **라이선스 한/영 2종류 전환 툴바**:
  - 메인 창 하단 **[📄 라이선스 및 약관 동의 고지서]**를 열고 상단 `[ 🇰🇷 KO ]` / `[ 🇺🇸 EN ]` 클릭 시 언어가 즉시 바뀌는지 확인.
- [ ] **독립형 스케줄러 원격 즉시 전원 제어**:
  - `PowerNetworkScheduler.exe`에서 대상 PC 선택 후 `🛑 대상 PC 즉시 종료` / `🔄 대상 PC 즉시 다시시작` 버튼이 작동하는지 확인.
- [ ] **보안 인증 토큰 및 비상 복구 센터**:
  - `PowerNetworkScheduler.exe`의 **[🚨 토큰 분실 복구]**에서 마스터 키를 이용한 토큰 조회 및 재설정이 정상 동작하는지 확인.
- [ ] **미니 위젯 5종 테마 및 설정 저장 지속성**:
  - `네온 링`, `사이버 HUD`, `초슬림 바`, `레트로 LED`, `클린 카드` 테마 변경 후 재부팅 시 `%APPDATA%\PowerController\power_timer_settings.json`에 영구 유지되는지 확인.
